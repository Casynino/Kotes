## Replacing these with real KOTES photography

Keep the same filenames and drop the new files in place — no code changes are
needed. Recommended: 1800px on the long edge, JPEG quality ~72, landscape 3:2.
If a subject changes meaningfully, update the matching `alt` text in
`src/content/media.ts`.
